## 推荐实现顺序

### 阶段 1：普通 Mesh 单根管道

验收标准：

- 使用普通 Mesh 显示一根管道。
- 管道长度、方向和位置正确。
- 管道外壳为透明或半透明材质。
- 能说明此阶段为什么暂不使用 `InstancedMesh`。
- 不影响现有设备模型和场景控制。

### 阶段 2：InstancedMesh 批量管道

验收标准：

- 多根相同管道共享 Geometry 和 Material。
- 每个实例拥有独立的位置、旋转和长度矩阵。
- 能说明 `InstancedMesh` 适合重复对象，不适合完全不同几何结构的对象。
- 与普通 Mesh 版本进行视觉和实现方式对比。

### 阶段 3：实例级别的状态和颜色

验收标准：

- 每个管道实例可以独立设置正常、预警、异常或停止状态。
- 实例颜色或 Shader 参数不会错误地同步到其他管道。
- 记录实例状态传递方式，例如 instance color 或实例属性。

### 阶段 4：TubeGeometry 弯曲管道

验收标准：

- 使用 `TubeGeometry` 创建至少一段弯曲管道。
- 能说明它与直线 `cylinderGeometry` 的适用边界。
- 不破坏普通 Mesh 和 `InstancedMesh` 的学习示例。

### 阶段 5：Shader 水流、发光和告警

验收标准：

- 管道内部有蓝色流动效果。
- 水流沿管道轴向移动。
- 支持 `uTime`、`uSpeed`、`uColor`、`uOpacity` 等 uniform。
- 速度为 0 时动画停止。
- 正常、预警、严重异常分别显示蓝色、橙色、红色效果。

### 阶段 6：接入监测状态

验收标准：

- `instantFlow` 能改变水流速度。
- `pumpRunning` 为 false 时水流停止。
- 正常、预警、严重异常分别显示蓝色、橙色、红色效果。
- 离线状态不会继续显示正常流动。

### 阶段 7：粒子水流（已完成）

验收标准：

- 蓝色粒子沿指定管道方向移动。
- 粒子速度跟随流量变化。
- 停止时粒子停止或隐藏。
- 异常时粒子变为橙色或红色。

### 阶段 7 后：管网视觉增强子阶段（已完成）
