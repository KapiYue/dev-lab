# 当前任务：登录认证基础与当前用户上下文

## 目标

在已有党员列表和详情查询的基础上，建立基础登录认证能力，明确当前登录用户，为后续功能权限和数据权限验证做准备。

目标链路：

登录请求 → 认证校验 → 当前用户上下文 → 受保护接口

## 待办

- [ ] 明确登录用户、密码和认证状态的数据模型。
- [ ] 实现登录请求 DTO、登录 Service 和登录接口。
- [ ] 实现基础认证凭证生成与校验机制。
- [ ] 建立当前登录用户上下文读取方式。
- [ ] 为党员列表或详情接口增加登录状态校验。
- [ ] 未登录访问受保护接口时返回统一错误 JSON。
- [ ] 验证登录成功场景。
- [ ] 验证用户名或密码错误场景。
- [ ] 验证未登录访问受保护接口场景。

## 完成标准

- [ ] 登录接口可以完成认证并返回统一 JSON。
- [ ] 已登录请求可以读取当前用户信息。
- [ ] 未登录请求无法访问受保护接口。
- [ ] 认证失败和未登录场景返回明确的统一错误 JSON。
